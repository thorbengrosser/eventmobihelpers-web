# EventMobi Brand Guidelines for UI Design

## 1. Logo Usage

### 1.1 Clear Space

Maintain clear space equal to the height of the letter **“t”** in *eventmobi* around all sides of the logo.

### 1.2 Minimum Size

* Minimum height: **0.375 inches (28 px)**
* Never display smaller than this to maintain legibility.

### 1.3 Logo Variants

* **Primary logo**: Full *EventMobi* wordmark with icon.
* **Icon-only logo**: Use **“E” symbol** only when horizontal space is severely constrained (e.g., favicon or app icon).

### 1.4 Limited Use Logos

* **Tall vertical logo**: Acceptable only when layout restricts horizontal space.
* **Rainbow logo**: Use **only** in LGBTQ2+ recruiting or inclusion-related materials.

### 1.5 Prohibited Modifications

Do **not**:

* Change logo colours
* Rotate or skew the logo
* Alter proportions or arrangement of icon and text
* Apply shadows, gradients, or other effects
* Place logo on complex or low-contrast backgrounds
* Stretch logo disproportionately

## 3. Typography

### 3.1 Fonts

| Role                     | Typeface           | Weight                  | Context                              |
| ------------------------ | ------------------ | ----------------------- | ------------------------------------ |
| **Headlines (H1)**       | Lato Black         | Bold / Black            | Print & Web                          |
| **Subheadlines (H2)**    | Lato Regular       | Regular / Semi-Bold     | Print & Web                          |
| **Body Copy (H3)**       | Proxima Soft Light | Regular / Semi-Bold max | Print & Web                          |
| **Body Copy (Web)**      | Nunito             | Regular / Semi-Bold max | Web only                             |
| **Fallback System Font** | Calibri            | Regular / Semi-Bold max | Use when web fonts unavailable       |
| **Labels / Pull Quotes** | Fertigo            | Regular / Script        | Short single-line use only           |
| **Fallback (Script)**    | System equivalent  | Regular / Script        | Use sparingly if Fertigo unavailable |

### 3.2 Type Hierarchy Examples

#### Correct Usage

```
(H1) Lato Black
(H2) LATO Regular
(S1) Lato Normal
Body: Proxima Soft or Nunito Regular
(S2) Lato Black
```

#### Incorrect Usage

* Using multiple colours within text hierarchy
* Script fonts for subheadlines
* Excessive letter spacing or bold body text
* All caps subheadlines
* Using non-approved fonts or misaligned line spacing

## 5. Shapes and Patterns

### 5.1 Orb Shape

* Organic, rounded curves that convey **humanity and playfulness**.
* Can be used:

  * Individually
  * As a cut-out
  * As an overlapping pattern background
* Avoid sharp or geometric distortions.

---

## 6. Accessibility & Application Notes

* Maintain sufficient **contrast ratio** (WCAG 2.1 AA) between foreground text and background.
* Avoid combining more than **two accent colours** per interface screen.
* Use **Lato or Proxima Soft** for all UI headings and labels; **Nunito** for in-app copy.
* Prefer white or light neutral backgrounds (`#C1C6C8` or `#D0D3D4`) to ensure readability and brand consistency.
* Favicon: use only the **“E” logo** on transparent background at `#EE7700`.
